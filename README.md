# Quran Audio-to-Ayah Indexer (POC)

A Python pipeline that produces per-ayah timestamps for full-surah Quran recitation audio using **forced alignment** — the canonical Arabic text is a known input, never generated.

## Why Forced Alignment?

| Approach | Hallucination Risk | Cost Model |
|----------|-------------------|------------|
| Open-vocabulary ASR | ❌ High — can generate/paraphrase sacred text | Per-token, ongoing |
| Video Indexer / Content Understanding | ❌ High — same issue | Per-minute, ongoing |
| **Forced Alignment** | ✅ Zero — text is input, not output | One-time compute |

Forced alignment **constrains** the recognizer to emit only the exact canonical Uthmani text you provide. The model's job is to find **where** each word occurs in the audio, not **what** the words are.

## Quick Start

```bash
# 1. Clone and install
git clone <repo>
cd quran-indexer
python -m venv .venv
.venv\Scripts\activate  # Windows
pip install -r requirements.txt

# 2. Configure
cp .env.example .env
# Edit .env with your settings

# 3. Run on a single surah (e.g., Al-Mulk = 67)
python -m src.pipeline --surah 67 --reciter Mishary_Alafasy

# 4. View results
cat data/output/067_Mishary_Alafasy.json
```

## Alignment Approach

This POC uses **WhisperX** with Arabic language support:

1. **Transcribe pass**: Whisper generates initial word timings
2. **Align pass**: wav2vec2 model refines word boundaries
3. **Force override**: We replace ASR text with canonical Uthmani text, keeping only timestamps
4. **Collapse**: Word timestamps → ayah spans (start_ms, end_ms)

The canonical text is **never** generated by the model — it comes from Tanzil.net/Quran.com API.

## Validation

We validate boundary accuracy against EveryAyah.com per-ayah clips:

```bash
python -m tests.validate_boundaries --surah 67 --reciter Mishary_Alafasy
```

Target: mean boundary error < 300ms.

## Cost Analysis

Forced alignment is a **one-time batch job**:

| Component | Cost Driver | Typical |
|-----------|-------------|---------|
| WhisperX inference | GPU-hours | ~1 min/surah on RTX 3090 |
| Text corpus API | Free tier | 0 |
| Azure AI Search | Per-document | ~$0.001/ayah |

No per-query token costs. No ongoing API calls for text generation.
